# SkillPay

## Setup Instructions

### Prerequisites
- Node.js v18+
- Git

### Installation
1. Clone: `git clone <repo-url>`
2. Backend: `cd server && npm install`
3. Frontend: `cd client && npm install`
4. Create `server/.env` (ask team for values)

### Run
- Backend: `cd server && npm run dev`
- Frontend: `cd client && npm run dev`
